## 3. 上一次对话留下的关键提醒

- C++ 文件内的 `#include <cstdio>` 切勿误写 `<cstudio>`。
- `std::printf("%f", ...)` 需要匹配 double 类型的实参；`std::cout` 通过 C++ 输出流接口工作。
- 前一节运动模拟：将 `delta_time` 从 1.0 改为 0.5，**单次位移减半**，相同 12 次循环时**总模拟时间减半**。
- 用户已正确理解 `std::` 为 C++ 标准库命名空间，`::` 为作用域解析运算符；建议优先显式书写 `std::`。
